# Smokes

흡연 기록·분석·예측 웹앱 (단일 `index.html`, 아이폰 홈 화면 앱 지원)

| 탭 | 기능 |
|---|---|
| 기록 | 원클릭 +1 기록, 날짜 지정 기록, 최근 기록 |
| 분석 | 시간대별·일별·월별 그래프, 패턴 리포트 |
| 예측 | 30일·6개월·1년 예측, 하루 목표·절약 |
| 계정 | 선택형 구글 로그인 동기화(Firebase), CSV 백업·불러오기 |

- 다크/라이트 모드, 한국어/English 전환
- 데이터는 기기(localStorage)에 먼저 저장되고, 로그인 시에만 클라우드와 합쳐져요.
- 배포: Netlify (`_redirects`로 Firebase 로그인 같은 주소 처리)
